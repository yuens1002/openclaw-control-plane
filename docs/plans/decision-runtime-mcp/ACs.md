## Gate 1: Plan To AC Coverage

Every deliverable D1-D9 must have at least one AC row. No AC may reference a
deliverable outside D1-D9. Re-run this check after any plan or AC revision.

## Gate 2: Anti-Drift

Pass conditions state behavioral invariants rather than tenant names, hosted
provider values, generated identifiers, secrets, or one live environment.
Stable protocol and public tool names are allowed where they define the reviewed
contract. Deterministic fixtures use only local endpoints and `example.*`
identities. Re-run this check before implementation and independent verification.
